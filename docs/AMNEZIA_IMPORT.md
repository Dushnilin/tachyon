# Импорт Amnezia `vpn://`

На активном **sing-box LX** поле «URL подключения» и текстовые подписки
принимают `vpn://` с конфигурацией WireGuard/AmneziaWG. Другие существующие
протоколы подключения сохраняются; новые алиасы `wg://`, `wireguard://`,
`awg://` не добавляются. Подсказка появляется только при выбранном LX,
а backend проверяет совместимость перед генерацией.

Поддержаны base64/base64url без обязательного padding, обычный INI `.conf`
с одним `[Interface]` и `[Peer]`, а также обычные и Qt qCompress-сжатые
JSON-экспорты Amnezia `amnezia-wireguard`, `amnezia-awg`, `amnezia-awg2`.
Из контейнера читается полный INI в `last_config.config` (объект или JSON-строка).
Используется `defaultContainer`; без него требуется единственный подходящий
контейнер. Другие протоколы, неоднозначные экспорты и конфигурации нескольких
пиров не поддержаны.

Импорт сохраняет поля AWG, включая диапазоны, `HeaderProtectionKey`,
`RandomTrailers`, `DisableCookies`, и создаёт sing-box `endpoints` вместо
устаревших WireGuard `outbounds`. Узлы доступны selector и URLTest.
Параметры не удаляются ради совместимости с другим ядром. Имя берётся из
фрагмента ссылки, описания экспорта либо комментария INI; AWG отображается
как **AmneziaWG**, обычный WG остаётся **WireGuard**. Исходная ссылка хранится
в метаданных интерфейса и не попадает в конфигурацию ядра.

Распаковка реализована на штатном ucode без новых пакетов, внешних команд
или сетевых загрузок декодеров. Лимиты: 131072 символа base64 и 65536 байт
распакованных данных. Backend проверяет deflate, длину, Adler-32 и параметры
WG/AWG; синхронный frontend для сжатых данных проверяет только оболочку.
Принятие ссылки кнопкой `+` не заменяет проверку backend перед применением.
INI-хуки не исполняются, реквизиты управления сервером из контейнера не
используются, DNS экспорта не заменяет DNS-настройки Tachyon.

Формат qCompress соответствует [официальному декодеру Amnezia](https://github.com/amnezia-vpn/config-decoder/blob/master/mainwindow.cpp).
Полный AWG 3.1 проверен на `sing-box 1.14.2-lx.11`: изолированная передача HTTPS
и импорт в рабочую секцию на OpenWrt. Пользователь подтвердил работу на роутере.
Это поддержка импорта Tachyon, а сам туннель реализован ядром LX.

Повторяемые проверки без приватных конфигураций: `bash tests/subscription_amnezia.sh`
и frontend-тесты `validateVpnUrl.test.js`. Проверяются сжатые блоки deflate,
повреждения, ограничения, сохранение ключей/полей, имя, метаданные,
публичный парсер, полная генерация и отказ на ядре без LX.
