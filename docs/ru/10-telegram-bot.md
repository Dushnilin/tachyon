# Telegram-бот и управление парком роутеров

[English](../en/10-telegram-bot.md) | [К оглавлению](README.md)

Tachyon 2.0 включает встроенного нативного Telegram-бота, работающего внутри основного сервиса `/usr/bin/tachyon` (без отдельного интерпретатора или cron-скриптов). Настройка выполняется в разделе `Настройки -> Telegram-бот`.

![Настройки Telegram-бота в веб-интерфейсе](../images/ru/15-telegram-bot.webp)

## Первичная настройка и права доступа

1. Получите токен бота у `@BotFather` и вставьте его в поле **`Токен Telegram-бота`** (`bot_token`).
2. Укажите ваш числовой Telegram ID (можно несколько через запятую) в **`Chat ID администраторов`** (`admin_ids`). Бот полностью игнорирует любые команды от пользователей, чьи ID не входят в `admin_ids`.
3. Задайте **`Имя роутера`** (`router_name`) — префикс в шапке всех сообщений для удобного различения нескольких роутеров в одном чате.
4. Настройте **`Интервал опроса`** (`poll_interval`, по умолчанию 5 сек) и при необходимости маршрут бота через конкретную секцию (`bot_proxy_section`) с резервным прямым подключением (`bot_direct_fallback`).
5. Включите переключатель **`Включить Telegram-бота`** и примените настройки.

## Событийные уведомления и тихие часы

Бот умеет оперативно отправлять алерты по ключевым событиям (каждый флаг настраивается независимо или через `/notifications`):

- Падение/перезапуск `tachyon-core` (`notify_crash`, `notify_restart`), срабатывание Watchdog.
- Переключение резервного или активного сервера (`notify_server_switch`, `notify_failover`), состояние WAN (`notify_wan`).
- Обновления подписок (`notify_subscription`), доступность новых версий компонентов (`notify_update_available`, `notify_auto_update`).
- Утечки DNS (`notify_dns_leak`), предупреждения маршрутов (`notify_route_alert`), аномалии `Smart Detect` (`notify_smart_detect`), события родительского контроля (`notify_parental`), TLS-сертификаты (`notify_cert`) и ловушка `honeypot` (`notify_honeypot`).
- Режим тихих часов (`/quiet`, `quiet_hours_enabled`, `quiet_hours_start` / `quiet_hours_end`) отключает звуковые или ночные уведомления в заданное окно времени.

## Управление парком роутеров (`managed_routers`)

Секция **мульти-роутерного управления** позволяет добавить дочерние роутеры OpenWrt под управлением Tachyon (`managed_routers` в конфиге) с адресом, портом и API-токеном. Команда **`/routers`** переключает контекст команд бота на удалённый роутер или выводит сводку состояния по всему парку сразу.

## Полный справочник команд Telegram-бота

### Главная навигация и статус
| Команда | Назначение |
|---|---|
| `/start`, `/menu`, `/help` | Главное интерактивное меню с кнопками управления |
| `/status`, `/core` | Сводка состояния системы, версий, памяти, CPU и аптайма ядра |
| `/cancel` | Отмена текущего пошагового ввода и возврат в меню |

### Маршрутизация, узлы и серверы
| Команда | Назначение |
|---|---|
| `/sections` (`/sec`, `/rules`) | Просмотр секций маршрутизации, их включение/отключение и выбор узлов |
| `/sources` (`/subs`, `/outbounds`) | Управление источниками и принудительное обновление подписок |
| `/ping` | Массовый замер задержки до всех активных узлов |
| `/failover` | Состояние групп резервирования и балансировщиков |
| `/servers` (`/srv`) | Просмотр и управление входящими серверами на роутере |
| `/fptn` | Быстрое управление параметрами/токеном FPTN |

### Управление ядром и сессиями
| Команда | Назначение |
|---|---|
| `/start_core` | Запуск ядра `tachyon-core` |
| `/stop_core` | Остановка ядра `tachyon-core` |
| `/restart` (`/reload`) | Пересборка конфигурации и перезапуск/reload ядра |
| `/close_conns` | Закрытие всех активных соединений |
| `/trim_ram` | Принудительная очистка кэшей памяти ядра |
| `/watchdog` | Быстрое включение или отключение Watchdog |

### Диагностика, DNS и пакетный десинхронизатор
| Команда | Назначение |
|---|---|
| `/doctor` | Системная диагностика (`run_local_doctor`) |
| `/ai_doctor` | Запуск AI-аудита конфигурации и логов |
| `/fix` | Доступ к быстрым исправлениям (`Quick Fix`) |
| `/trace` | Симуляция маршрутизации (`route_explain`) для домена или IP |
| `/dns` | Управление режимом DNS и просмотр резолверов |
| `/leak` | Проверка утечек DNS / IPv6 / WebRTC |
| `/fuzzer` | Запуск подбора оптимальной стратегии пакетной десинхронизации |
| `/logs` | Просмотр последних строк журнала ядра и сервиса |
| `/support` | Сборка и отправка архива/файла `support_bundle` прямо в чат |

### Устройства, семья и гости
| Команда | Назначение |
|---|---|
| `/devices` | Список LAN-устройств, трафик и привязка правил |
| `/wol` | Отправка Magic Packet (Wake-on-LAN) указанному устройству |
| `/parental` | Управление семейными профилями и суточными квотами |
| `/schedules` | Просмотр и переключение расписаний |
| `/guest` | Состояние и переключение гостевого режима |

### Резервные копии, обновления и настройки бота
| Команда | Назначение |
|---|---|
| `/snapshots`, `/backup` | Список сохранённых снимков конфигурации и создание ручного бэкапа |
| `/lkg`, `/rollback` | Просмотр последней рабочей конфигурации (LKG) и немедленный откат |
| `/updates`, `/update_lists` | Проверка обновлений компонентов и ручное обновление списков `.trs` |
| `/routers` | Переключение и статус удалённых роутеров парка |
| `/notifications` (`/notify`), `/quiet` | Настройка уведомлений по типам событий и расписания тихих часов |
| `/toggles` (`/features`) | Быстрое переключение глобальных опций роутера |
| `/bot_settings`, `/lang`, `/name` | Настройки бота, переключение языка интерфейса (`ru`/`en`) и имени роутера |
